스마트폰 앱 설치 및 웹 주소(URL) 배포 안내

📱 1. 모바일 앱 만들기 (홈 화면에 설치)

다운로드한 파일을 매번 찾지 않고 스마트폰 바탕화면에서 터치 한 번으로 실행할 수 있습니다.

  • 삼성/안드로이드 (크롬·삼성인터넷): 브라우저 메뉴(⋮) 클릭 ➔ '홈 화면에 추가' 또는 '앱 설치' 선택
  • 아이폰/iPad (사파리): 하단 공유 버튼(⎋) 클릭 ➔ 스크롤하여 '홈 화면에 추가(➕)' 선택
  • 효과: 주소창 없는 깔끔한 전체화면 네이티브 앱처럼 동작하며 바탕화면에 앱 아이콘이 생성됩니다.

🌐 2. 인터넷 웹 주소(URL)로 배포하기 (무료 1분 완성)

다운로드 파일 없이 누구나 URL 링크를 타고 들어와 사용할 수 있는 무료 호스팅 방법입니다.

방법 ① Vercel (가장 추천, 초간단):
vercel.com 가입 ➔ 압축 해제한 폴더를 웹사이트에 드래그 앤 드롭 ➔ 5초 만에 https://korea-tour.vercel.app 형태의 평생 무료 HTTPS 웹 주소 생성!
방법 ② Netlify Drop:
app.netlify.com/drop 접속 ➔ 폴더를 브라우저에 끌어다 놓기만 하면 즉시 무료 웹 주소 발급!
방법 ③ GitHub Pages:
GitHub 저장소 생성 후 파일 업로드 ➔ Settings의 Pages 메뉴에서 Branch 활성화 시 https://아이디.github.io/프로젝트명 주소 제공!
