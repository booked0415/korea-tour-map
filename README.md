# 🗺️ 대한민국 관광·축제 인터랙티브 지도 웹앱 (Korea Tour Map)

대한민국 전국 17개 시·도 및 8도 광역 지역의 대표 축제와 주요 관광명소를 실시간으로 조회하고 코스를 계획할 수 있는 네이버·구글 지도 스타일의 PWA 웹 애플리케이션입니다.

## 🌟 주요 기능
1. **실시간 축제 상태 판별**: 2026년 기준 '오늘 진행중 (LIVE)', '개최 예정 (D-Day)', '상시 운영', '행사 종료' 자동 계산
2. **전국 8도 및 17개 시·도 지역 필터링**: 서울, 경기, 인천, 강원, 충청, 전라, 경상, 제주 권역별 원터치 지도 이동 및 목록 추출
3. **네이버 / 카카오 지도 길찾기 연동**: 도로명 정밀 주소 기반 1초 검색
4. **PWA (Progressive Web App) 탑재**: 스마트폰 홈 화면에 전체화면 앱으로 원클릭 설치 가능
5. **완전 무인 자동화 (GitHub Actions)**: 매일 오전 7시 / 오후 5시 최신 축제 정보 자동 수집 및 Vercel 자동 배포

## ⚙️ 자동화 구조 (GitHub Actions ➔ Vercel)
- `.github/workflows/update_festivals.yml`: 매일 오전 7시와 오후 5시(KST)에 동작하는 스케줄러
- `scripts/update_festivals.py`: 최신 축제 상태 계산 및 데이터베이스 자동 동기화 스크립트
- 커밋이 발생하면 Vercel이 5초 만에 감지하여 프로덕션 웹사이트에 즉시 자동 반영합니다.
